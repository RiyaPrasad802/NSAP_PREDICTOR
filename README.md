# NSAP Pension Eligibility Prediction

## Project Overview

This project focuses on developing a machine learning-based approach to pension eligibility prediction under the National Social Assistance Programme (NSAP), using district-wise pension data from AI Kosh.

The project explores data preprocessing, machine learning classification, model evaluation, and deployment using IBM watsonx.ai.

## Objectives

* Explore and prepare district-wise pension data.
* Develop a machine learning classification pipeline.
* Apply IBM watsonx.ai AutoAI for model experimentation.
* Evaluate the trained model.
* Deploy the trained model using IBM watsonx.ai.

## Tools and Technologies

* Python
* Jupyter Notebook
* IBM watsonx.ai AutoAI
* Decision Tree Classifier
* Machine Learning

## Project Workflow

1. **Data Preparation:** Worked with the district-wise pension dataset obtained from AI Kosh.
2. **Model Development:** Explored machine learning pipelines using IBM watsonx.ai AutoAI.
3. **Classification:** Worked with a Decision Tree classification pipeline.
4. **Model Evaluation:** Used the model evaluation workflow to assess the trained model.
5. **Deployment:** Successfully deployed the model on IBM watsonx.ai.

## Model Deployment

* Platform: IBM watsonx.ai
* Deployment Name: `NSAP_AIML`
* Model Type: Machine Learning Classification

The deployed model can be used through its scoring interface, subject to the IBM deployment environment and access permissions.
